# To-do – Erzählwerk

Android-App fürs Tablet: Die KI schreibt Romane, du gibst die Richtung vor – per Text oder mit Bildern. Beliebig viele Romane im Bücherregal. Bilder über ComfyUI (PC), Text über Ollama (PC) oder Gemma auf dem Tablet, wenn der PC aus ist. Am Ende Buch (PDF/EPUB) und Hörbuch.

- [x] **1. Grundgerüst** – Bücherregal mit mehreren Romanen (anlegen, Titel/Genre/Idee, löschen), Einstellungen: Gemma E2B/E4B (Modelle geteilt mit Character Fun), Ollama mit automatischem Rückfall aufs Tablet, ComfyUI-Verbindung, KI-Test
- [x] **2. Welt** – Figuren, Orte, Kleidung mit Tags und Vorschaubildern, Tag-Liste mit Baukasten; Import aus Character Fun
- [x] **3. Plot** – Idee als Text oder aus Bildern (Gemma beschreibt sie) → Exposé und Kapitelplan (Kapitel → Szenen mit Ort, Figuren, Inhalt), alles änderbar
- [x] **4. Schreiben** – Szene für Szene, Stil/Länge/Perspektive/Zeitform, Weiterschreiben, Umschreiben, Neu würfeln; laufende Zusammenfassung für den roten Faden
- [x] **5. Bilder** – Szenenbild pro Szene und Titelbild über ComfyUI
- [x] **6. Buch** – PDF und EPUB, mit oder ohne Bilder
- [x] **7. Hörbuch** – eine Stimme (Android-Sprachausgabe), kapitelweise als Audiodateien, im Hintergrund mit Fortschritt
